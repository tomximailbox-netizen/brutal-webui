单域名 DNS 解析测试

测试服务器能否通过 DNS 解析该域名的 IPv4 与 IPv6

💡 同步逻辑说明：

1. 系统自动解析文件中所有域名的 IPv4 与 IPv6 地址。

2. 解析出的新 IP 自动执行限速：IPv4 默认 /32，IPv6 默认 /128。

3. 已不在域名解析结果中的旧 IP 会自动执行 del 清理（手动临时 IP 自动保护不被删除）。

4. 若 DNS 全部解析失败，为防止误删将自动放弃执行。

IP/CIDR 格式快速校验

💡 静态 IP 清单说明：

1. 本清单存储于 brut_ip.txt 文件中，服务器重启后永久持久化保留。

2. 支持 IPv4（未加掩码默认 /32）与 IPv6（未加掩码默认 /128），支持自定义掩码如 /24 或 /64。

3. 此文件中的所有规则自动纳入免清理白名单，在后台定时同步刷新时绝不被误删。

4. 页面查看的临时手动 IP 支持一键转存到此清单中。
